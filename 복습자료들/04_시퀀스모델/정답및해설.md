# 시퀀스 모델 문제 정답 및 해설

먼저 `시퀀스모델복습.ipynb`의 빈 셀을 직접 채운 뒤 비교하세요. 랜덤 수열의 loss와 신경망 예측값은 난수 상태에 따라 달라질 수 있습니다. 정답을 확인할 때는 특정 로짓보다 Tensor shape, gate 계산식, PAD 제외 방식과 train/eval 분리를 우선 확인하세요.

## 1. 순차 데이터와 기본 RNN

### 문제 1. 같은 값, 다른 순서

```python
ascending = torch.tensor([1.0, 2.0, 3.0, 4.0])
descending = torch.tensor([4.0, 3.0, 2.0, 1.0])

print(ascending.sum(), descending.sum())
print(torch.equal(ascending, descending))             # False
print(torch.equal(ascending.sort().values,
                  descending.sort().values))          # True
```

두 수열은 값의 빈도와 합이 같지만 위치별 값은 다릅니다. 빈도만 세는 BoW 방식은 이 순서를 버립니다. 자연어에서도 `개가 사람을 물었다`와 `사람이 개를 물었다`처럼 단어 순서와 조사가 관계를 바꿉니다.

### 문제 2. RNN 입출력 shape

```python
B, L, F, H = 2, 4, 3, 5
rnn_input = torch.randn(B, L, F)
rnn = nn.RNN(
    input_size=F,
    hidden_size=H,
    batch_first=True,
)
output, hidden = rnn(rnn_input)

print(rnn_input.shape)  # (2, 4, 3)
print(output.shape)     # (2, 4, 5)
print(hidden.shape)     # (1, 2, 5)
assert torch.allclose(output[:, -1, :], hidden[-1])
```

`B`는 배치 크기, `L`은 시퀀스 길이, `F`는 위치별 입력 특성 수, `H`는 은닉 상태 차원입니다. `output`에는 모든 위치의 마지막 층 상태가, `hidden`에는 각 층·방향의 최종 상태가 들어갑니다.

### 문제 3. 은닉 상태에서 로짓으로

```python
binary_head = nn.Linear(H, 1)
logits = binary_head(hidden[-1])
probabilities = torch.sigmoid(logits)
predictions = probabilities.ge(0.5).long()

print(logits.shape, probabilities.shape)  # (2, 1)
print(predictions)
```

로짓은 sigmoid 전의 제한 없는 실수 점수이고, 확률은 sigmoid로 `0~1`에 매핑한 값입니다. 이진 분류에서 확률 `0.5`는 로짓 `0`과 같습니다.

### 문제 4. 순서 분류 데이터

```python
sequence_length = 12
example_count_per_class = 40
base_up = torch.linspace(0, 1, sequence_length)
base_down = torch.flip(base_up, dims=[0])

up_sequences = (
    base_up.repeat(example_count_per_class, 1)
    + 0.05 * torch.randn(example_count_per_class, sequence_length)
)
down_sequences = (
    base_down.repeat(example_count_per_class, 1)
    + 0.05 * torch.randn(example_count_per_class, sequence_length)
)

train_x = torch.cat([up_sequences[:32], down_sequences[:32]])
train_y = torch.cat([torch.ones(32), torch.zeros(32)])
validation_x = torch.cat([up_sequences[32:], down_sequences[32:]])
validation_y = torch.cat([torch.ones(8), torch.zeros(8)])

train_order = torch.randperm(len(train_x))
validation_order = torch.randperm(len(validation_x))
train_x = train_x[train_order].unsqueeze(-1)
train_y = train_y[train_order]
validation_x = validation_x[validation_order].unsqueeze(-1)
validation_y = validation_y[validation_order]

all_x = torch.cat([train_x, validation_x])
all_y = torch.cat([train_y, validation_y])
print(all_x.shape, all_y.shape)  # (80, 12, 1), (80,)
print(torch.bincount(all_y.long()))
```

각 분할에 상승·하강이 모두 들어가도록 클래스별로 먼저 나눈 뒤 섞었습니다. 전체에서 무작위로만 자르면 작은 데이터에서는 한 분할의 클래스 비율이 우연히 치우칠 수 있습니다.

### 문제 5. RNN 분류기

```python
class SequenceRNNClassifier(nn.Module):
    def __init__(self, input_size=1, hidden_size=8):
        super().__init__()
        self.rnn = nn.RNN(
            input_size,
            hidden_size,
            batch_first=True,
        )
        self.classifier = nn.Linear(hidden_size, 1)

    def forward(self, inputs):
        _, hidden = self.rnn(inputs)
        return self.classifier(hidden[-1]).squeeze(-1)

sequence_model = SequenceRNNClassifier(hidden_size=8)
print(sequence_model(train_x[:5]).shape)  # (5,)
```

마지막 출력은 sigmoid 확률이 아니라 `BCEWithLogitsLoss`에 넣을 `(B,)` 로짓입니다.

### 문제 6. 한 배치 학습

```python
criterion = nn.BCEWithLogitsLoss()
optimizer = optim.Adam(sequence_model.parameters(), lr=0.01)

batch_x = train_x[:16]
batch_y = train_y[:16].float()
optimizer.zero_grad()
batch_logits = sequence_model(batch_x)
loss = criterion(batch_logits, batch_y)
loss.backward()
optimizer.step()
print(batch_logits.shape, batch_y.shape, loss.item())
```

`BCEWithLogitsLoss`가 sigmoid와 binary cross entropy를 수치적으로 안정되게 결합하므로 손실 전에 sigmoid를 적용하지 않습니다. 레이블은 로짓과 같은 shape의 실수 `0/1`이어야 합니다.

### 문제 7. 학습·검증 루프

```python
train_loader = DataLoader(
    TensorDataset(train_x, train_y),
    batch_size=16,
    shuffle=True,
)
loss_history = []

for epoch in range(30):
    sequence_model.train()
    total_loss = 0.0
    total_count = 0
    for batch_x, batch_y in train_loader:
        optimizer.zero_grad()
        logits = sequence_model(batch_x)
        loss = criterion(logits, batch_y.float())
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * len(batch_y)
        total_count += len(batch_y)
    loss_history.append(total_loss / total_count)

sequence_model.eval()
with torch.no_grad():
    validation_logits = sequence_model(validation_x)
    validation_probabilities = torch.sigmoid(validation_logits)
    validation_predictions = validation_probabilities.ge(0.5).long()
    validation_accuracy = (
        validation_predictions == validation_y.long()
    ).float().mean().item()
print(loss_history[-1], validation_accuracy)
```

`train()`은 학습 모드, `eval()`은 Dropout·BatchNorm 같은 계층의 평가 동작을 선택하며 `no_grad()`는 gradient 기록을 끕니다.

### 문제 8. 기본 RNN의 한계

RNN은 같은 순환 가중치를 시간축으로 반복 곱합니다. 길이 100은 길이 12보다 이 연쇄가 훨씬 길어 Jacobian의 크기가 0에 가까워지거나 매우 커질 가능성이 큽니다. 기울기 소실은 앞쪽 위치로 전달되는 gradient가 거의 0이 되는 현상이고, 기울기 폭주는 gradient가 비정상적으로 커지는 현상입니다.

```python
optimizer.zero_grad()
logits = sequence_model(batch_x)
loss = criterion(logits, batch_y.float())
loss.backward()
torch.nn.utils.clip_grad_norm_(
    sequence_model.parameters(),
    max_norm=1.0,
)
optimizer.step()
```

Clipping은 큰 gradient의 norm을 제한해 폭주를 완화하지만 이미 0에 가까워진 gradient를 복원하지 않으므로 소실의 해결책은 아닙니다.

## 2. LSTM의 셀 상태와 게이트

### 문제 9. LSTM 반환값

```python
lstm = nn.LSTM(F, H, batch_first=True)
lstm_output, (lstm_hidden, lstm_cell) = lstm(rnn_input)
print(lstm_output.shape)  # (2, 4, 5)
print(lstm_hidden.shape)  # (1, 2, 5)
print(lstm_cell.shape)    # (1, 2, 5)
assert torch.allclose(lstm_output[:, -1, :], lstm_hidden[-1])
```

Hidden은 현재 출력에 가까운 단기 상태, cell은 gate를 통해 더 직접적으로 이어지는 장기 기억 경로입니다.

### 문제 10. LSTM gate 가중치

```python
w_ih = lstm.weight_ih_l0
w_hh = lstm.weight_hh_l0
b_ih = lstm.bias_ih_l0
b_hh = lstm.bias_hh_l0
print(w_ih.shape, w_hh.shape, b_ih.shape, b_hh.shape)
# (20, 3), (20, 5), (20,), (20,)

# PyTorch 저장 순서: input, forget, candidate, output
w_ii, w_if, w_ig, w_io = torch.chunk(w_ih, 4, dim=0)
w_hi, w_hf, w_hg, w_ho = torch.chunk(w_hh, 4, dim=0)
b_ii, b_if, b_ig, b_io = torch.chunk(b_ih, 4, dim=0)
b_hi, b_hf, b_hg, b_ho = torch.chunk(b_hh, 4, dim=0)
print(w_ii.shape, w_if.shape, w_ig.shape, w_io.shape)
# 각 (5, 3)
```

첫 축이 `4H`인 이유는 네 gate의 행이 한 Tensor에 이어 저장되기 때문입니다.

### 문제 11. LSTM 첫 step 직접 계산

```python
x_t = rnn_input[:, 0, :]
h_prev = torch.zeros(B, H)
c_prev = torch.zeros(B, H)

i_t = torch.sigmoid(x_t @ w_ii.T + b_ii + h_prev @ w_hi.T + b_hi)
f_t = torch.sigmoid(x_t @ w_if.T + b_if + h_prev @ w_hf.T + b_hf)
g_t = torch.tanh(   x_t @ w_ig.T + b_ig + h_prev @ w_hg.T + b_hg)
o_t = torch.sigmoid(x_t @ w_io.T + b_io + h_prev @ w_ho.T + b_ho)
c_t = f_t * c_prev + i_t * g_t
h_t = o_t * torch.tanh(c_t)

single_output, (single_h, single_c) = lstm(
    rnn_input[:, :1, :],
    (h_prev.unsqueeze(0), c_prev.unsqueeze(0)),
)
print(torch.allclose(h_t, single_output[:, 0, :], atol=1e-6))
print(torch.allclose(h_t, single_h[0], atol=1e-6))
print(torch.allclose(c_t, single_c[0], atol=1e-6))
```

`@`는 행렬곱이고 `f_t * c_prev`, `i_t * g_t`, `o_t * tanh(c_t)`의 `*`는 같은 위치끼리의 원소별 곱입니다.

### 문제 12. RNN·LSTM 파라미터 수

```python
rnn_12 = nn.RNN(3, 5)
lstm_12 = nn.LSTM(3, 5)

def parameter_count(module):
    return sum(parameter.numel() for parameter in module.parameters())

for name, module in (("RNN", rnn_12), ("LSTM", lstm_12)):
    print(name, parameter_count(module))
    for parameter_name, parameter in module.named_parameters():
        print(parameter_name, tuple(parameter.shape))
```

RNN은 `15 + 25 + 5 + 5 = 50`, LSTM은 네 gate 때문에 `60 + 100 + 20 + 20 = 200`개입니다. 더 많은 파라미터는 표현력을 늘리지만 더 많은 데이터·계산과 정규화가 필요하고 과적합 위험도 커지므로 항상 더 좋은 것은 아닙니다.

### 문제 13. 다층·양방향 LSTM

```python
bi_lstm = nn.LSTM(
    F,
    H,
    num_layers=2,
    bidirectional=True,

bi_output, (bi_hidden, bi_cell) = bi_lstm(rnn_input)
```

마지막 층의 방향 상태는 끝의 두 항 `[-2]`, `[-1]`입니다. `hidden[-1]`만 쓰면 역방향 상태만 남고 정방향 최종 정보를 잃습니다.

### 문제 14. LSTM 분류 출력층


학습 모드의 Dropout은 일부 특성을 무작위로 0으로 만들고 남은 값을 보정하지만, 평가 모드에서는 모든 특성을 사용합니다. 3-class 단일 레이블 분류라면 `nn.Linear(2*H, 3)`과 `nn.CrossEntropyLoss`, `(B,) long` 클래스 ID를 사용합니다.

## 3. GRU와 가변 길이

### 문제 15. GRU 반환값

```python
gru = nn.GRU(F, H, batch_first=True)
gru_output, gru_hidden = gru(rnn_input)
print(gru_output.shape)  # (2, 4, 5)
print(gru_hidden.shape)  # (1, 2, 5)
assert torch.allclose(gru_output[:, -1, :], gru_hidden[-1])
```

GRU는 update·reset gate로 하나의 hidden 상태를 갱신하므로 별도 cell을 반환하지 않습니다. GRU와 LSTM 모두 단순 RNN의 장기 의존성·gradient 흐름을 개선하려는 gated 순환 모델입니다.

### 문제 16. GRU gate 직접 계산

```python
gru_w_ir, gru_w_iz, gru_w_in = torch.chunk(
    gru.weight_ih_l0, 3, dim=0
)
gru_w_hr, gru_w_hz, gru_w_hn = torch.chunk(
    gru.weight_hh_l0, 3, dim=0
)
gru_b_ir, gru_b_iz, gru_b_in = torch.chunk(
    gru.bias_ih_l0, 3, dim=0
)
gru_b_hr, gru_b_hz, gru_b_hn = torch.chunk(
    gru.bias_hh_l0, 3, dim=0
)
# PyTorch gate 순서: reset r, update z, new n
x_t = rnn_input[:, 0, :]
h_prev = torch.zeros(B, H)
r_t = torch.sigmoid(
    x_t @ gru_w_ir.T + gru_b_ir
    + h_prev @ gru_w_hr.T + gru_b_hr
)
z_t = torch.sigmoid(
    x_t @ gru_w_iz.T + gru_b_iz
    + h_prev @ gru_w_hz.T + gru_b_hz
)
n_t = torch.tanh(
    x_t @ gru_w_in.T + gru_b_in
    + r_t * (h_prev @ gru_w_hn.T + gru_b_hn)
)
h_t = (1 - z_t) * n_t + z_t * h_prev

single_gru_output, single_gru_hidden = gru(
    rnn_input[:, :1, :],
    h_prev.unsqueeze(0),
)
assert torch.allclose(
    h_t,
    single_gru_output[:, 0, :],
    atol=1e-6,
)
```

Update gate `z`가 1에 가까우면 이전 상태를 더 유지하고 0에 가까우면 후보 상태를 더 받아들입니다.

### 문제 18. PAD·OOV ID

```python
train_sentences_18 = [
    "영화 정말 재미 있다",
    "영화 전혀 재미 없다",
    "배우 연기 좋다",
]
new_sentences_18 = ["영화 정말 좋다", "처음 보는 단어"]
token_counts = Counter(
    token
    for sentence in train_sentences_18
    for token in sentence.split()
)
ordered_tokens = sorted(
    token_counts,
    key=lambda token: (-token_counts[token], token),
)
PAD_ID, OOV_ID = 0, 1
word_to_id = {"<PAD>": PAD_ID, "<OOV>": OOV_ID}
word_to_id.update({
    word: index
    for index, word in enumerate(ordered_tokens, start=2)
})

def encode_sentence(text):
    tokens = text.split()
    if not tokens:
        tokens = ["<OOV>"]
    return [word_to_id.get(token, OOV_ID) for token in tokens]

encoded_sentences = [
    encode_sentence(sentence)
    for sentence in new_sentences_18
]
print(word_to_id, encoded_sentences)
```

`처음`, `보는`, `단어`는 모두 1이 됩니다. ID는 행 주소이며 크기가 의미·중요도 순서가 아닙니다.

### 문제 19. 오른쪽 패딩과 길이

```python
MAX_LENGTH = 6

def encode_and_pad(text):
    ids = encode_sentence(text)[:MAX_LENGTH]
    length = max(len(ids), 1)
    padded = ids + [PAD_ID] * (MAX_LENGTH - len(ids))
    return padded, length

encoded_pairs = [
    encode_and_pad(sentence)
    for sentence in new_sentences_18
]
token_ids = torch.tensor(
    [row for row, _ in encoded_pairs],
    dtype=torch.long,
)
lengths = torch.tensor(
    [length for _, length in encoded_pairs],
    dtype=torch.long,
)
print(token_ids, token_ids.shape, lengths)
assert token_ids.shape == (2, 6)
assert encode_and_pad("")[1] == 1
```

빈 문자열은 OOV 하나로 바꾸어 packed sequence가 요구하는 양의 길이를 보장합니다.

### 문제 20. Packed GRU 분류기

```python
class GRUSentenceClassifier(nn.Module):
    def __init__(
        self,
        vocabulary_size,
        embedding_dim=8,
        hidden_size=16,
        pad_id=0,
    ):
        super().__init__()
        self.embedding = nn.Embedding(
            vocabulary_size,
            embedding_dim,
            padding_idx=pad_id,
        )
        self.gru = nn.GRU(
            embedding_dim,
            hidden_size,
            batch_first=True,
        )
        self.classifier = nn.Linear(hidden_size, 1)

    def forward(self, input_ids, lengths):
        # (B, L) -> (B, L, E)
        embedded = self.embedding(input_ids)
        packed = pack_padded_sequence(
            embedded,
            lengths.cpu(),
            batch_first=True,
            enforce_sorted=False,
        )
        _, hidden = self.gru(packed)
        # (1, B, H) -> (B, H) -> (B,)
        return self.classifier(hidden[-1]).squeeze(-1)

gru_classifier = GRUSentenceClassifier(len(word_to_id))
gru_logits = gru_classifier(token_ids, lengths)
print(token_ids.shape, gru_logits.shape)
```

Packing은 PAD step을 순환 계산에서 건너뛰게 하며, `enforce_sorted=False`는 길이 내림차순으로 미리 정렬하지 않은 배치를 허용합니다.

## 4. NSMC 감성 분류

### 문제 21. 파일과 결측치

```python
source_candidates = [
```

Train은 파라미터 학습, validation은 하이퍼파라미터·early stopping 선택, test는 모든 선택이 끝난 뒤 최종 일반화 평가에 사용합니다. 같은 자료를 여러 역할에 쓰면 선택 과정의 정보가 평가에 누수됩니다.

### 문제 24. NSMC BiGRU

```python
class NSMCBiGRU(nn.Module):
    def __init__(
        self,
        vocabulary_size,
        embedding_dim=64,
        hidden_size=64,
        dropout=0.3,
        pad_id=0,
    ):
        super().__init__()
        self.embedding = nn.Embedding(
            vocabulary_size,
            embedding_dim,
            padding_idx=pad_id,
        )
        self.gru = nn.GRU(
            embedding_dim,
            hidden_size,
            batch_first=True,
            bidirectional=True,
        )
        self.dropout = nn.Dropout(dropout)
        # forward 64 + backward 64 = 128
        self.classifier = nn.Linear(2 * hidden_size, 1)

    def forward(self, input_ids, lengths):
        embedded = self.embedding(input_ids)
        packed = pack_padded_sequence(
            embedded,
            lengths.cpu(),
            batch_first=True,
            enforce_sorted=False,
        )
        _, hidden = self.gru(packed)
        sentence_vectors = torch.cat(
            [hidden[-2], hidden[-1]],
            dim=1,
        )
        return self.classifier(
            self.dropout(sentence_vectors)
        ).squeeze(-1)
```

`embedding_dim=64`, `hidden_size=64`일 때 분류층 입력은 `128`입니다.

### 문제 25. 학습·검증과 오분류

다음 코드는 `train_ids/train_lengths/train_labels`와 같은 방식으로 만든 validation Tensor가 있다고 가정한 핵심 답안입니다.

```python
train_loader = DataLoader(
    TensorDataset(train_ids, train_lengths, train_labels),
    batch_size=64,
    shuffle=True,
)
validation_loader = DataLoader(
    TensorDataset(
        validation_ids,
        validation_lengths,
        validation_labels,
    ),
    batch_size=64,
    shuffle=False,
)

model = NSMCBiGRU(len(nsmc_word_to_id))
criterion = nn.BCEWithLogitsLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(3):
    model.train()
    for ids, batch_lengths, labels in train_loader:
        optimizer.zero_grad()
        logits = model(ids, batch_lengths)
        loss = criterion(logits, labels.float())
        loss.backward()
        optimizer.step()

all_targets, all_predictions, all_probabilities = [], [], []
model.eval()
with torch.no_grad():
    for ids, batch_lengths, labels in validation_loader:
        logits = model(ids, batch_lengths)
        probabilities = torch.sigmoid(logits)
        predictions = probabilities.ge(0.5).long()
        all_targets.extend(labels.tolist())
        all_predictions.extend(predictions.tolist())
        all_probabilities.extend(probabilities.tolist())

misclassified_rows = [
    {
        "document": validation_texts[index],
        "target": target,
        "prediction": prediction,
        "positive_probability": probability,
    }
    for index, (target, prediction, probability) in enumerate(zip(
        all_targets,
        all_predictions,
        all_probabilities,
    ))
    if target != prediction
]
misclassified_df = pd.DataFrame(misclassified_rows)
print(misclassified_df)
```

`0.5` 부근 오분류는 결정 경계가 불확실하거나 정보가 부족함을 시사합니다. `0` 또는 `1`에 가까운 확신형 오분류는 label 오류, 부정어·반어·OOV 손실, 데이터 편향 또는 calibration 문제를 우선 점검해야 합니다.
